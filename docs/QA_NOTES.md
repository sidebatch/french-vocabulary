- Today queue can allow Seen to starve overdue reviews.

# v2.7.1 Auto-spelling regression fix

User real-device feedback found that `자동`/mix study never produced typing questions.

Root cause confirmed in code:
- `CORE = [meaning, listening, reverse]`
- automatic `cardSkillForReview(..., 'mix')` chose only CORE skills
- new-word automatic secondary choice contained only listening/reverse

Fix:
- added `autoSpellingEligible`
- added shared `autoSecondarySkill`
- eligible new-word secondary tasks use spelling at ~20%
- due auto reviews allow spelling at ~12%
- non-due reinforcement allows spelling at ~22%
- Weak/core due logic remains prioritized
- spelling is still not part of mastery requirements

Static QA:
- JavaScript syntax: PASS
- card count: 2,866
- card IDs unique: PASS
- explicit spelling mode preserved
- Smart and Custom auto paths both reference the new auto-spelling mixer
